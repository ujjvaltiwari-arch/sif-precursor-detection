# Higgsfield Visual Assets

This directory contains visual assets generated using Higgsfield for the SIF Precursor Detection project.

## Required Assets

Place the following assets in this directory:

- `hero-industrial.webp` — Industrial/mining environment for hero section
- `ai-analysis.webp` — AI analysis visualization
- `safety-worker.webp` — Worker safety imagery
- `risk-detection.webp` — Risk detection visual
- `dashboard-preview.webp` — Dashboard preview image

## Notes

- The application works without these assets (graceful fallback)
- Assets should be WebP format for optimal performance
- Max recommended size: 500KB per asset
- Do not use copyrighted images
