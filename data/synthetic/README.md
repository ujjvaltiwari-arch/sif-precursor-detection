# Synthetic / Demo Data

**NOTICE**: All data in this directory is **synthetic and generated for demonstration purposes only**.

This data does **NOT** represent real Oil India Limited (OIL) safety reports.

Synthetic data is clearly marked with:
- `is_synthetic: true`
- `label_source: "synthetic"`

When official OIL datasets become available, they should be placed in `data/raw/` and loaded separately.
